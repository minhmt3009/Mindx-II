Mục tiêu

Xây dựng pipeline ETL hoàn chỉnh để xử lý dữ liệu chiến dịch marketing ngân hàng từ CSV vào Data Warehouse, tự động hóa bằng Airflow.

Dữ liệu

File Bank.csv chứa 11,162 bản ghi với 17 cột thông tin khách hàng: tuổi, nghề nghiệp, hôn nhân, khoản vay, kết quả chiến dịch, v.v.

🏗️

Kiến trúc

3 layers: Raw (landing zone) → ETL (staging + cleaning) → DW (fact table). Mỗi layer có schema riêng trong PostgreSQL.

🐳

Triển khai

Toàn bộ chạy trong Docker containers: PostgreSQL 15, Airflow 2.8.1 (webserver + scheduler), sử dụng LocalExecutor.

RAW Layer

Tất cả cột lưu dạng TEXT. TRUNCATE + INSERT mỗi lần chạy. Giữ nguyên dữ liệu gốc.

ETL Layer

Parse kiểu dữ liệu, validate rules (age 18-100, balance, deposit yes/no...). Loại bỏ bản ghi lỗi.

DW Layer

Fact table cuối cùng. TRUNCATE + INSERT đảm bảo idempotent, không duplicate khi chạy lại.

🔍 Data Validation & Quality

✅ Validation Rules

  • age: 18 – 100 tuổi
  • balance: phải là số nguyên hợp lệ
  • marital: married / single / divorced
  • default, housing, loan, deposit: yes / no
  • day: 1 – 31, month: jan – dec
  • duration ≥ 0, campaign ≥ 1
  • pdays ≥ -1, previous ≥ 0

🛡️ Chống Duplicate

  • TRUNCATE + INSERT (idempotent) ở mỗi layer
  • RESTART IDENTITY reset auto-increment
  • Validate row count: staging == dw
  • Check duplicate theo toàn bộ business columns

📝 Logging

  • etl.etl_log ghi nhận mỗi step
  • Status: START → SUCCESS / FAIL
  • Mỗi lần chạy có RUN_ID riêng
